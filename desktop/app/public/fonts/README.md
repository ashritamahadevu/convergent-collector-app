# Inter

Unmodified Inter 4.1 variable upright web font by Rasmus Andersson and the Inter
Project Authors. Bundled for offline desktop rendering, including the Figma
Regular, Medium, Semi Bold and Bold aliases. No operating-system installation
or external font CDN is required at runtime.

Source: https://github.com/rsms/inter/tree/v4.1

Font: https://raw.githubusercontent.com/rsms/inter/v4.1/docs/font-files/InterVariable.woff2
